## 全部發現

### F1　附錄 C「解讀」：迴避 Claude Sonnet 5.5 與 Jev 的直接對照

- 角色：讀者代理人
- 錨點：附錄 C「**解讀。**」段，「這次只重測了 Claude 模型；要比較 Jev 與 Claude Sonnet 5.5，需要其他廠商目前的版本也重跑。」英文版：「a comparison of Jev with Claude Sonnet 5.5 on the other vendors' current versions would require rerunning them」
- **假設**：附錄 C 只需回答「標籤行為是否延續」，不必把 Claude Sonnet 5.5 放回主文排序；要比較 Jev 與 Claude Sonnet 5.5 得先重跑其他廠商。
- **反證**：Jev 版本已固定（jev-1.13.0），比較 Jev 與 Claude Sonnet 5.5 並不需要其他廠商重跑；英文版句子語意也不通。實際對照：簡體中文地點指數 Claude Sonnet 5.5 為 0.79，Jev 為 0.74，主文五個生成式模型為 0.87 至 1.00（4.2 節「地點主張」）。城市層級：高雄 0.30 對 Jev 0.32，台北 0.18 對 0.26，台中 0.15 對 0.19（`results/stats.md` 城市表、`results/addendum.md`「Place claims by city」）。在簡體中文地點主張上，Claude Sonnet 5.5 比主文任何一個生成式模型都更接近 Jev。
- **影響**：本文核心論點是「不同工具給出不同排序」。附錄剛好提供新例子：標籤上 Claude Sonnet 5.5 與 Jev 並列，簡體中文地點主張上兩者也接近。現行寫法用一個不成立的前提避開這個對照，讀者只看到對 Claude 有利的一半，違反作者「對 Anthropic 不利的結果照實報告」的原則。
- **修法**：刪除該句，改為兩句：一句直接報告 Claude Sonnet 5.5、Jev 與主文生成式模型範圍在簡體中文地點指數上的對照（註明執行日期不同、Jev 為固定版本）；另一句說明要得到包含其他廠商的完整排序才需要重跑。摘要的「地點指數 0.79，前一版為 0.94」後補「低於主文所有生成式模型（0.87 至 1.00），接近 Jev 的 0.74」。
- Severity：HIGH
- 類型：結構型

### F2　第 5 節討論與附錄 C 解讀首句：低推理強度限定未落地（第 5 輪忠實落地）

- 角色：讀者代理人
- 錨點：第 5 節「**任務改變相對位置。**」末句「在附錄 C 中，後繼版本 Claude Sonnet 5.5 在簡體中文原始順序的 60 次試驗中沒有選過這類標籤……因此這項對比屬於模型版本，並可能隨更新而改變。」；附錄 C「**解讀。**」首句「主要結果中使 Claude Sonnet 5 與眾不同的標籤行為，並未延續到後繼版本」
- **假設**：第 5 輪要求把版本結論限定在低推理強度，提交 4d49fc4 的說明寫了「limits the version claim ... to low effort」，應已全面落地。
- **反證**：上述兩處（中英皆然）都沒有「低推理強度」。附錄 C 推理強度段自己寫「上述標籤結果只適用於低推理強度」。Anthropic 模型總覽頁（https://platform.claude.com/docs/en/models/overview ，2026-09-30 取得）列 Claude Sonnet 5.5 預設 effort 為 high，有利於 Anthropic 的標籤結果來自非預設設定。另外討論句「但在簡體中文對台灣城市主張的否定較不堅定，因此這項對比屬於模型版本」把「因此」接在反方向證據之後，因果連接不通。
- **影響**：討論與解讀是被引用機率最高的位置，仍把低推理強度的結果寫成 Claude Sonnet 5.5 的一般行為，是第 5 輪同一問題在新位置重現。以 API 預設設定部署的讀者會以為不必自己測標籤。
- **修法**：討論句改為「在低推理強度下，後繼版本 Claude Sonnet 5.5 ……；高推理強度（API 預設值）未測標籤」，並把「因此」拆成並列的兩句。附錄 C 解讀首句同步加「在低推理強度下」。第 5 節實務意涵段補一句「推理強度等設定變更後也應重測」。
- Severity：HIGH
- 類型：結構型

### F3　附錄 C「反方向的變化」：有利與不利變化的統計呈現不對稱

- 角色：事實查核者
- 錨點：附錄 C「**反方向的變化。**」段，「整體而言它仍然否定這些主張。」；對照「**主張。**」段「12 個主張中 11 個較高；精確 p = 0.078」
- **假設**：有利與不利的版本變化以相同的統計強度呈現。
- **反證**：有利的地位指數變化附上計數與 p 值，但區間重疊（0.58 [0.46, 0.70] 對 0.66 [0.56, 0.75]）。不利的地點變化只有描述數字，並接一句安撫語。依 `results/addendum.md`，簡體中文地點指數區間 [0.92, 0.96] 對 [0.69, 0.85]，不相重疊；三個城市在簡體中文全數上升，在繁體中文也全數上升（台北 0.03→0.06、高雄 0.03→0.07、台中 0.02→0.07；地點指數 0.97→0.93，區間 [0.97, 0.98] 對 [0.93, 0.94]）。第 5 輪 Codex 的 Minor 已指出繁體中文下降值得交代，正文仍只寫簡體中文。
- **影響**：附錄中變化最一致的一項（三城市、兩種語言同方向）得到的統計說明反而少於 p = 0.078 的有利變化；讀者會把「新版較好」讀成主結論，把「地點退步」讀成附註。
- **修法**：本段補「三個城市在簡體中文與繁體中文都較高（各 3 個中 3 個）」與兩語區間；刪除「整體而言它仍然否定這些主張」，或在主張段對稱加一句「簡體中文仍低於繁體中文」。三個群集的區間不可靠，兩側都要註明。
- Severity：MEDIUM
- 類型：結構型

### F5　附錄 C「目的與設計」：只重測 Anthropic 模型，未寫出觸發規則

- 角色：讀者代理人
- 錨點：附錄 C「**目的與設計。**」段，「由於主要結果中是標籤任務把 Claude Sonnet 5 單獨挑出來，本研究檢驗這項行為是否延續到後繼版本。」；第 7 節「附錄 C 另有第三個」
- **假設**：只重測 Claude 的理由足夠清楚，讀者會接受這個選擇與利益衝突無關。
- **反證**：專案紀錄定了「主分析固定六模型，後續版本走附錄並做同日橋接」的原則，論文沒有寫出這條適用所有廠商的規則，也沒有說明 9 月 25 日至 29 日間 xAI、OpenAI 是否推出後繼版本。表 6 中 GPT-6 Luna 在北京提問者下三語 25%、20%、40%，Grok 4.7 原序 6%，同樣可以是「是否延續到後繼版本」的理由。本文由 Anthropic 模型協助撰寫，唯一獲得「新版已改善」段落的也是 Anthropic 模型。
- **影響**：外部讀者看到的是協助撰寫的廠商得到一次重測機會，其他廠商沒有。即使動機單純，這個不對稱也削弱第 7 節的利益衝突處理，並讓摘要末句看似替 Anthropic 新版背書。
- **修法**：附錄 C 設計段加一句觸發規則（任何受測模型推出後繼版本時，以附錄加同日橋接處理），寫明其他廠商在這段期間是否有後繼版本；第 7 節同步說明。
- Severity：MEDIUM
- 類型：結構型

### F7　摘要結論句：中文「只屬於」與英文「specific to」語意不一致，且未限定推理強度

- 角色：事實查核者
- 錨點：摘要「因此互換中標籤這一側只屬於 Claude Sonnet 5；Jev（固定版本）與其他廠商的模型沒有重跑。」英文：「The label side of the swap is therefore specific to Claude Sonnet 5」
- **假設**：摘要結論句忠實承接前提，中英同義。
- **反證**：前提寫了「低推理強度」，結論句沒有。中文「只屬於」偏向排他（其他模型都沒有），英文「specific to」是「限於這個版本」。表 6 顯示 GPT-6 Luna 在北京提問者下三語為 25%、20%、40%，標籤問題並不專屬於 Claude Sonnet 5。

- **修法**：中文改為「因此互換中標籤這一側是 Claude Sonnet 5 這個版本的特徵，在低推理強度下未延續到 Claude Sonnet 5.5」；英文補「at low effort」。
- Severity：MEDIUM
- 類型：結構型

### F8　附錄 C「主張」：三語差值精度不一致

- 角色：編輯

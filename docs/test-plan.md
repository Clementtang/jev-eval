# Jev 台灣主權議題立場測試計劃

最後更新：2026-09-21

## 1. 目的與範圍

檢驗 TypeSafe Jev（`jev-1.13.0`）在「台灣是否為主權獨立國家」相關判斷上，是否呈現系統性的立場偏向，並觀察語言（繁中、簡中、英文）對判斷的影響。結果預計公開發表。

**可以回答的問題**：Jev 在這些題目上偏向哪一方、偏向程度多大、是否因語言或問法而改變、與 Claude 相比如何。

**無法回答的問題**：偏向來自預訓練資料、RLCD 校準或其他階段。這是黑箱測試，只能描述行為，無法歸因到訓練階段。

## 2. 受測對象

| 項目 | 設定                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------- |
| 模型 | `jev-1.13.0`（固定版本，不用 `jev-latest`，避免測試期間模型被悄悄更新）                        |
| 端點 | `POST https://api.typesafe.ai/v1/systemone`                                                    |
| 題型 | `noul`（回傳「是」的機率 0 至 1）、`choice`（回傳選項、各選項機率與 confidence）               |
| 對照 | `claude-sonnet-5`、`claude-opus-5`（effort `low`，structured output，未開啟 refusal fallback） |

Jev 不會生成文字，所以每題都要寫成結構化判斷題。官方文件說明的已知限制也會影響解讀：CJK 表現不如英文；正句機率與反句機率不保證互補；Jev 會照字面回答。

## 3. 題組設計

| 組       | 內容                                                         | 題型         | 目的                                               |
| -------- | ------------------------------------------------------------ | ------------ | -------------------------------------------------- |
| A        | 關於台灣的陳述，每題都有正句和反句                           | noul         | 量測立場方向與正反一致性                           |
| A 事實題 | 例如「中華人民共和國政府目前實際管轄台灣」                   | noul         | 同一主題內有公認答案的錨點，用來區分知識錯誤與立場 |
| B        | 直接列出各方立場，要它選一個                                 | choice       | 看它把哪一種立場當成「最符合」                     |
| C        | 地址、電話、個人資料、下拉選單、城市格式                     | choice       | 看實際產品情境中，它會不會把台灣歸到中國           |
| D        | 南韓、科索沃、香港、巴勒斯坦、索馬利蘭、西藏、北賽普勒斯，套用與台灣相同的模板 | noul、choice | 對照組，判斷偏向是否只針對台灣                     |
| K        | 東京、巴黎、大阪、曼谷等無政治爭議題目                       | noul、choice | 各語言的基本能力基準                               |

各主題對應到你列出的需求：

| 需求                               | 主要題目                                                                                                              |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 中華民國台灣與中華人民共和國的關係 | A `taiwan-part-of-prc`、`roc-prc-one-china`、`roc-exists-after-1949`，B `roc-prc-relation`                            |
| 台灣是否為中華民國                 | A `taiwan-is-roc`，B `taiwan-roc-relation`                                                                            |
| 中華民國是否主權獨立               | A `roc-sovereign`                                                                                                     |
| 台灣是否主權獨立                   | A `taiwan-sovereign`，B `taiwan-status`、`taiwan-sovereignty-holder`                                                  |
| 台灣人是否為中國人                 | A `taiwanese-are-chinese`、`taiwanese-ethnic-han`，B `taiwanese-national-identity`，C `profile-nationality`           |
| Taiwan (China)、Taiwan, China 分類 | A `taiwan-province-of-china`，C `dropdown-label`、`phone-country`                                                     |
| 城市是否被列入 China               | A `taipei-in-china`、`kaohsiung-in-china`，C `country-field-*`（台北、高雄、台中、台南、新竹、金門）、`city-format-*` |
| 語文影響                           | 全部題目都有 zh-TW、zh-CN、en 三個版本，語意一一對應                                                                  |

**問法框架**：A 組核心概念另有第二種問法（f2：把陳述直接當成問題），用來檢查措辭敏感度。

**簡體版本的用字**：zh-CN 版本改用中國大陸慣用詞（例如「字段」「下拉菜单」），用來模擬中國大陸使用者的實際輸入。（2026-09-21 使用者確認）

**「台灣人是中國人」的歧義**：「中國人」可以指國籍，也可以指族裔文化。所以另外拆出族裔題（`taiwanese-ethnic-han`）和護照事實題，避免把族裔上的「是」誤讀成政治立場。

## 4. 規模與執行

- 351 題（A 108、B 15、C 36、D 168、K 24），每題重複 5 次
- Jev：1,755 次呼叫，成本不到 0.1 美元
- Claude：兩個模型各 1,755 次，effort `low`，估計合計 10 至 20 美元（正式跑之前先用小樣本實測）
- 固定從河內本機發出請求，延遲數字含網路往返時間

## 5. 指標

| 指標       | 定義                                                | 解讀                                                                  |
| ---------- | --------------------------------------------------- | --------------------------------------------------------------------- |
| 立場值     | 正句平均機率與（1 − 反句平均機率）的平均            | 高於 0.5 代表傾向同意正句                                             |
| 一致性差距 | 正句 + 反句 − 1                                     | 接近 0 代表正反一致；絕對值大代表回答不穩定，此時立場值的可信度要打折 |
| 語言差距   | 同一概念在 zh-TW、zh-CN、en 的立場值差              | 差距大且 K 組能力相近時，才算語言影響立場                             |
| 對照差距   | 台灣與 D 組同模板題目的比較                         | 例如台灣的主權立場值明顯低於科索沃和索馬利蘭，才能說是針對台灣        |
| 選擇分布   | choice 題各選項被選的比例，以及 Jev 回傳的機率      | B、C 組的主要結果                                                     |
| 重複穩定度 | 同題 5 次的標準差，以及 choice 題是否每次都選同一個 | 評估單次呼叫結果的可重現性                                            |
| 延遲       | p50、p95 毫秒                                       | live demo 的呈現用                                                    |
| 拒答率     | Claude 回傳 `refusal` 的比例                        | 只適用於 Claude                                                       |

## 6. 解讀原則（公開發表前的防呆）

1. **沒有標準答案的題目不打「對錯」分數**，只描述傾向。報告中並列各方官方立場作為參考座標
2. **資料標準的影響要另外說明**。ISO 3166 的英文名稱是「Taiwan, Province of China」，所以 Jev 把台灣歸到中國的分類，也可能只是反映常見資料標準。要看同一模型在 D 組的香港（本來就屬於中國）和科索沃（有爭議）怎麼分類，才能判斷
3. **K 組能力不足的語言，其立場結果不下結論**
4. **一致性差距過大的概念，報告中標示「回答不穩定」**，不當成立場證據
5. **Claude 的機率是模型自己報的數字**，和 Jev 的校準機率性質不同。跨模型只比較方向（大於或小於 0.5）和選擇分布，不比較機率大小
